# CS23334-Fundamentals-Of-Data-Science-Laboratory-Record
Repository description
A compact, reproducible Data Science course record containing curated Python notebooks and scripts for end-to-end exploratory data analysis, preprocessing, statistical testing, visualization, and baseline machine learning models.

Highlights
- Hands‑on notebooks for data visualization and EDA using Matplotlib, Seaborn, and Plotly.
- Preprocessing utilities: missing value handling, outlier detection and treatment, feature scaling, encoding.
- Machine learning baselines: Linear Regression, Logistic Regression, K-Nearest Neighbors, K-Means clustering.
- Statistical tests: t-test, z-test, and ANOVA (F-test) with interpretation notes.
- Reproducible examples with toy datasets and clear, commented code for teaching and reference.

Repository layout
-/Record
-/Research Paper from the project
- README.md — project overview and quick start

Quick start
- Clone the repo.
- Create a virtual environment and install requirements (pandas, numpy, scikit-learn, scipy, matplotlib, seaborn, plotly).
- Open notebooks in /notebooks for guided walkthroughs or run scripts from /scripts for reproducible pipelines.

Intended audience and use
Designed for students, instructors, and practitioners who want a concise teaching-ready reference of practical data-prep techniques, basic statistical inference, visualization best practices, and simple ML baselines.
